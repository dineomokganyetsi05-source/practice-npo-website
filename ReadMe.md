Dog Paw is a non-profit organisation (NPO) that supports animals in need. The organisation was established in 2020 during the COVID-19 lockdown by people who care about animals.

The website provides information about Dog Paw, its services, and how people can get involved or offer support.

Website Pages

Home: Introduces Dog Paw and its purpose. About: Provides information about the organisation. Services: Explains the services offered. Enquiry: Allows visitors to make enquiries. Contact: Provides contact information.

Technologies Used

HTML — for the website structure. CSS — for styling, colours, layout and background images. JavaScript — for interactive features and form validation.

Project Features

Navigation links between website pages. Responsive layout for different screen sizes. Website background image. Forms for visitor enquiries. JavaScript functionality and form validation.

Project Files

HTML files contain the website pages. style.css contains the website styling. script.js contains JavaScript functionality. images/ contains the website images. CHANGELOG.md records changes made to the website. References.md contains the sources used for the project.
